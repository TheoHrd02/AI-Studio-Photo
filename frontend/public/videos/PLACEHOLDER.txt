🎬 VIDÉOS DE TEST / PLACEHOLDER

Pour tester rapidement le carousel sans créer de vraies vidéos :

1. Utilisez des URLs de vidéos publiques (temporaire):
   - Pexels Videos: https://www.pexels.com/fr-fr/videos/
   - Pixabay Videos: https://pixabay.com/fr/videos/
   - Coverr: https://coverr.co/

2. Éditez config/hero.config.ts avec des URLs directes:

export const heroVideos: HeroVideoConfig[] = [
  {
    url: 'https://player.vimeo.com/external/456456456.hd.mp4?s=XXXXX',
    alt: 'Video 1',
  },
]

3. Ou utilisez une vidéo de test générée:
   - Créez une vidéo de 10s avec un fond uni
   - Ajoutez du texte "VIDEO 1", "VIDEO 2", etc.
   - Exportez en MP4 < 2MB

4. Services de vidéos gratuites pour l'IA:
   - RunwayML (https://runwayml.com/)
   - Synthesia (pour des démos)
   - D-ID (pour talking heads)

Une fois vos vraies vidéos prêtes, placez-les ici et supprimez ce fichier.
